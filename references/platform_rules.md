# 平台写作规范 — 微信公众号

> 本文件在 [4/8] 写作 步骤被读取。
> 不同平台有不同的调性和套路，写之前先看这里。

---

## 一、微信公众号核心特征

| 维度 | 特征 |
|------|------|
| **阅读场景** | 手机端，碎片化，通勤/睡前/午休 |
| **注意力窗口** | 标题3秒定生死，前150字决定是否看完 |
| **传播机制** | 朋友圈转发 + 在看 + 收藏，裂变靠情绪 |
| **读者心理** | "关我什么事" > "学到了什么" > "转给别人看" |
| **算法权重** | 完读率 > 在看率 > 转发率 > 收藏率 |
| **字数甜区** | 短文800-1500字，长文2000-3500字，中老年800-1200字 |

## 二、标题公式（Hook 优先级最高）

### 爆款标题5要素（至少命中3个）

| 要素 | 说明 | 示例 |
|------|------|------|
| **具体数字** | 给读者一个"可量化"的预期 | "3种""60岁""10年""5000块" |
| **特定人群** | 让读者对号入座 | "女人过了50""农村老人""当妈的" |
| **悬念/反转** | 打破预期，制造信息差 | "最怕不是没钱，而是…""不是感情，是这3样" |
| **情绪钩子** | 激发好奇/愤怒/共鸣/焦虑 | "当场就炸了""只回了一句话" |
| **否定式** | "不是A，是B"制造认知冲突 | "拼的不是感情""最怕不是没钱" |

### 标题模板（直接套用）

```
1. [人群] + [否定] + [数字] + [悬念]
   → "女人过了60岁才发现，婚姻晚年拼的不是感情，是这3样东西"

2. [冲突场景] + [情绪爆发] + [悬念收尾]
   → "婆婆嘴对嘴喂孙子，儿媳当场就炸了，婆婆只回了一句话"

3. [数字] + [人群] + [反常识结论]
   → "50岁以后才明白的10个道理，第7个最扎心"

4. [具体事件] + [时间跨度] + [情感反转]
   → "请保姆半个月跑了两个，我才读懂婆婆带娃的委屈"

5. [日常场景] + [冲突升级] + [悬念]
   → "婆婆追着喂饭，儿媳说了句别喂了，婆婆当场摔碗"
```

### 标题禁忌

| 禁忌 | 原因 |
|------|------|
| 超过25字 | 微信标题折叠，后半段看不到 |
| 用书名号/引号 | 占字符，视觉杂乱 |
| 纯陈述无悬念 | "我的婆婆来带孩子了" — 没人点 |
| AI腔标题 | "深入探讨隔代育儿的多元维度" — 没人点 |
| 标题党无内容 | 点进来发现货不对板，掉粉 |

## 三、开头钩子（前150字）

### 5种开头策略（写作时随机选1种）

**策略1：直接冲突（适合情感/矛盾类）**
```
不铺垫，不介绍背景，直接把读者扔进冲突现场。

❌ "婆媳关系自古以来就是一个复杂的话题……"
✅ "婆婆用嘴嚼碎了肉，喂给一岁半的孙子。我说了句'妈别这样'，她回我：'你老公是我这么喂大的，死了吗？'"
```

**策略2：悬念场景（适合故事/反思类）**
```
抛出一个反常场景，让读者好奇"为什么"。

❌ "今天我想和大家分享一下关于带孩子的感受……"
✅ "第二个保姆走的那天晚上，我在客厅坐到凌晨两点。"
```

**策略3：数字冲击（适合数据/观点类）**
```
用一个具体数字开头，制造信息冲击。

❌ "很多人在中年时会面临各种问题……"
✅ "我妈今年57岁，存款3万2，每月退休金2200。她上个月跟我说：'我要是病了，你别给我治。'"
```

**策略4：对话切入（适合生活/情感类）**
```
用一段真实对话开头，读者立刻进入场景。

❌ "最近发生了一件事让我很感慨……"
✅ "'你一个月给你妈多少钱？'闺蜜突然问我。我愣了一下，说两千。她笑了：'我给我妈五千，她转头就给了我弟。'"
```

**策略5：反常识断言（适合观点/干货类）**
```
先说一个违反直觉的结论，再解释为什么。

❌ "关于婚姻，有很多需要注意的地方……"
✅ "过了60岁的夫妻，感情好不好已经不重要了。重要的是三样东西，跟爱情没半毛钱关系。"
```

## 四、正文写作规范

### 段落节奏

| 规则 | 说明 |
|------|------|
| 每段不超过4行 | 手机屏幕一屏能看完，不滚动 |
| 段间留空行 | 视觉呼吸感，降低阅读疲劳 |
| 长短句交替 | 连续3个长句后插1个短句 |
| 对话独立成段 | 引用的话单独一行，前后空行 |

### 语气调性

| 场景 | 调性 | 示例 |
|------|------|------|
| 情感故事 | 朋友聊天，不端着 | "说出来不怕你笑话" |
| 观点评论 | 有态度，但不爹味 | "我觉得这事吧，真不能怪她" |
| 干货教程 | 过来人分享，不说教 | "踩过坑才知道，这3步不能省" |
| 中老年向 | 朴实温暖，不花哨 | "日子嘛，就是一天一天过的" |

### 口语化标记词（主动使用）

这些词让文章有"人味"，`humanness_score.py` 的暖词库会检测：

```
吧 | 呢 | 嘛 | 啊 | 哈 | 唉 | 哎 | 哦 | 嗯
说实话 | 老实说 | 坦白讲 | 讲真
我觉着 | 我以为 | 依我看 | 个人感觉
```

### 避坑清单

| 坑 | 怎么避 |
|----|--------|
| 爹味说教 | 用"我"的经历替代"你"应该 |
| 万能金句 | "生活就像一面镜子"→ 删掉，写具体的事 |
| 情绪扁平 | 有高有低，不要全程煽情或全程理性 |
| 完美收尾 | 不用每篇都"愿我们都能…",可以留白/反问/自嘲 |
| AI式结构 | 禁止 首先/其次/最后，禁止 一方面/另一方面 |

## 五、中老年受众专项规范

### 字数控制
- 短文：350-500字（一条朋友圈的阅读量）
- 标准：800-1200字（一个泡脚的时间）
- 长文：不超过2000字（中老年耐心有限）

### 内容偏好
- **故事 > 道理**：用具体的人和事说话，不要抽象分析
- **冲突 > 和谐**：先写矛盾再写和解，不要平铺直叙
- **数字 > 形容词**："存了3万2"比"存了一些钱"有冲击力
- **对话 > 描述**：让人物自己说话，不要作者旁白

### 禁忌
- 不用网络梗（中老年看不懂）
- 不用英文缩写（除非是"APP"这种普及的）
- 不用"破防了""绝绝子""YYDS"等年轻化表达
- 不用复杂的比喻链（一个比喻说清楚就够）

## 六、SEO 关键词布局

| 位置 | 规则 |
|------|------|
| 标题 | 含核心关键词（1-2个） |
| 前150字 | 主关键词自然出现1次 |
| H2小标题 | 覆盖长尾搜索意图 |
| 正文 | 关键词密度2-3%（每千字20-30次） |
| 结尾 | 核心关键词再现1次 |
