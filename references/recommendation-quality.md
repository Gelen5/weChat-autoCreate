# 微信推荐质量门禁

这是独立于反 AI 评分和一般合规检查的发布前门禁，依据微信对公众号和服务号推荐内容的低创作度要求，重点减少同质化、搬运改写、信息不足、低价值 AIGC、标题正文不匹配和图文素材质量问题。

## 结果边界

- `pass`：当前检查范围内未发现明显阻断项。
- `pass_with_notes`：可继续，但有人工复核提醒。
- `needs_revision`：必须修改并重新检查。
- `blocked`：禁止创建草稿或发布。

门禁不承诺微信官方推荐，也不等同于官方审核。未配置历史索引时必须显示“无法证明与过往内容不重复”。

## 核心规则

1. 比较标题、正文片段和图片，不接受只改标题或替换同义词。
2. 核心段落需要具体场景、时间、地点、人物、数据、来源、步骤或作者判断。
3. 数据、研究、专家观点、健康功效和官方结论必须有来源；无法核验时改为观点或删除。
4. 标题不能使用无依据绝对化、恐慌表达，也不能承诺正文没有提供的内容。
5. 正常 AI 辅助不直接判低质，但批量模板、虚构事实和缺少原创材料会被拦截。
6. 图片需存在、可读取、清晰且不重复；贴图号每张图应承担不同信息或叙事功能。

推荐质量不能替代一般合规检查。还要继续拦截虚假信息、侵权搬运、低俗或性别对立表达、过期信息、虚假人设、无价值营销、站外导流和规避平台治理行为。医疗、财经、教育、司法等内容优先使用权威来源，并写明适用范围和时间。

```powershell
python -m toolkit.cli recommendation-check article.md --strict
python -m toolkit.cli recommendation-check article.md --history-dir .\history --output report.json
python -m toolkit.cli recommendation-check article.md --strict --repair-output article-repaired.md
```

自动修复只删除套话和收窄部分绝对化标题；缺少来源、原创材料、图片或事实时必须人工补充，禁止自动编造。修复后必须完整复检。
