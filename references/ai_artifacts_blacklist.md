# AI 痕迹黑名单 — 禁用词 + 替换建议

> 本文件在 [4/8] 写作 和 [5/8] 反AI 步骤被读取。
> 不是告诉你"不能用什么"，而是告诉你"用了之后怎么改"。

---

## 使用方法

1. **写作时**：扫一眼这张表，记住这些词不要出现在你的文章里
2. **自检时**：用 `humanness_score.py` 跑一遍，命中禁用词就查这张表找替换
3. **修复时**：不是机械替换，要理解"为什么这个词像AI"和"换成什么才像人"

---

## 一、结构性过渡词（AI最爱用的"连接零件"）

| AI禁用词 | 为什么像AI | 替换建议 | 改写逻辑 |
|---------|-----------|---------|---------|
| 值得注意的是 | AI用来假装"我要说重点了" | 直接说那件事，不用预告 | 人不会预告"我要说重点"，直接说重点 |
| 值得一提的是 | 同上，AI口头禅 | 删掉，直接写事实 | 如果真值得提，读者自己会看到 |
| 需要指出的是 | AI式严肃声明 | 删掉，或换成"有个事得说" | 口语里没人这么说 |
| 综上所述 | AI总结模板 | 用具体的事收尾 | 人不会在结尾贴标签"我在总结" |
| 总而言之 | 同上 | 用一个场景/细节收尾 | 用画面替代概括 |
| 由此可见 | AI逻辑链条标志 | 删掉，让读者自己推 | 不用帮读者画箭头 |
| 换言之 | AI换种说法重复 | 删掉重复，只说一次 | 人类不会说一遍再换个说法再来一遍 |
| 与此同时 | AI平行叙事标志 | 换成"那会儿""就在那阵子" | 口语用时间词，不用书面连词 |
| 在此基础上 | AI递进模板 | 删掉，直接说下一步 | 人会说"然后呢"不会说"在此基础上" |
| 从这个角度来看 | AI视角切换 | 删掉，直接说观点 | 人切换视角不会先报备 |
| 此外/另外 | AI并列标志 | 用句号断开，或者"还有个事" | 口语里用断句替代连接词 |

## 二、绝对化表达（AI喜欢"盖棺定论"）

| AI禁用词 | 为什么像AI | 替换建议 | 改写逻辑 |
|---------|-----------|---------|---------|
| 不言而喻 | AI式"这还用说" | 写出来到底是什么 | 如果真不言而喻就别说了，说了就写具体 |
| 毋庸置疑 | AI式权威背书 | 删掉，或换成"这是真的" | 口语里质疑/不质疑都不用这词 |
| 不可否认 | AI式让步 | 换成"确实""话说回来" | 人会说"确实吧"不会说"不可否认" |
| 不得不说 | AI式被迫承认 | 换成"说实话""讲真" | 人会主动说，不会"不得不说" |
| 事实上/实际上 | AI式事实声明 | 删掉，直接写 | 这些词出现时后面跟的多半是AI编的 |
| 显而易见 | AI式"你应该知道" | 写出具体证据 | 人要么不写，要么写出为什么明显 |
| 如前所述 | AI式回指 | 删掉，或换成"刚才说的那个" | 口语回指用"那个""刚才的" |
| 正如我们所知 | AI式共同体假设 | 删掉 | 你不知道读者知不知道 |

## 三、修饰性套话（AI的"万能形容词"）

| AI禁用词 | 为什么像AI | 替换建议 | 改写逻辑 |
|---------|-----------|---------|---------|
| 至关重要 | AI万能重要标记 | 写出具体后果/影响 | 重要不重要看后果，不看标签 |
| 不可忽视 | 同上 | 写出忽略会怎样 | 同上 |
| 双刃剑 | AI万能比喻 | 写出具体的好处和坏处 | 这个比喻已经被用烂了 |
| 扮演着重要的角色 | AI万能角色描述 | 写出到底干了什么 | 角色重不重看做了什么事 |
| 颠覆性/革命性 | AI万能震撼词 | 写出到底改变了什么 | 真颠覆不用说颠覆 |
| 划时代/跨时代 | 同上 | 写出具体对比 | 用"以前怎样，现在怎样"替代 |
| 令人瞩目 | AI万能惊叹 | 写出具体数字/事实 | 让读者自己惊，不用你代惊 |
| 令人惊叹 | 同上 | 同上 | 同上 |
| 令人兴奋 | 同上 | 同上 | 同上 |
| 深入探讨 | AI式学术腔 | 换成"仔细看了看""研究了下" | 口语不探讨，口语看/研究/琢磨 |
| 全面解析 | AI式大全标记 | 删掉，直接写内容 | 真全面不用标"全面" |
| 深度解读 | 同上 | 同上 | 同上 |

## 四、句式结构（AI的"骨架特征"）

> 这些不是单个词，而是**句子的组织方式**。`humanness_score.py` 会检测这些模式并扣分。

| AI句式 | 为什么像AI | 怎么改 | 示例 |
|-------|-----------|-------|------|
| **首先…其次…最后** | AI三段论排比，机械感极强 | 打乱顺序，用具体事件驱动叙事 | ❌ 首先要早起，其次要运动，最后要吃早饭 → ✅ 早起这事最难。运动还好，吃完早饭出门走走 |
| **一方面…另一方面** | AI平行分析标志 | 选一面写深，另一面一笔带过 | ❌ 一方面好，另一方面不好 → ✅ 好处是能省钱。坏处嘛，累 |
| **虽然…但是…平衡** | AI绝对对比模板 | 让其中一面占主导，不做完美平衡 | ❌ 虽然累但是充实，达到了平衡 → ✅ 累是真的累。但充实也是真的 |
| **不仅…而且** (≥2次) | AI递进堆叠 | 用断句替代，一件事说透 | ❌ 不仅快而且稳，不仅便宜而且好用 → ✅ 快，还稳。便宜，也好用 |
| **然而值得注意/需要指出** | AI转折+预告二合一 | 删掉预告，直接转折 | ❌ 然而值得注意的是 → ✅ 但是/结果 |

## 五、口语化替换词库（写作时主动用这些）

| 场景 | AI腔 | 人味替换 |
|------|------|---------|
| 让步 | 不可否认/不可否认地 | 确实吧/话说回来/讲真 |
| 强调 | 值得注意的是/需要指出 | 有个事得说/这里有个坑 |
| 总结 | 综上所述/总而言之 | 说白了/到头来/反正就是 |
| 转折 | 然而/与此同时 | 但是/话说/结果 |
| 递进 | 在此基础上/此外 | 还有/再说/另外 |
| 推断 | 由此可见/显而易见 | 你看/这么一看/懂了吧 |
| 态度 | 毋庸置疑/不容忽视 | 这是真的/跑不掉的 |
| 预告 | 正如我们所知/如前所述 | 刚才说的那个/你知道的 |

## 六、检测与修复流程

```
1. 写完文章 → 跑 humanness_score.py
2. 看 pattern layer 的 forbidden_words_count
   - 0 → 通过
   - >0 → 查本表找替换词
3. 看 sentence_structure_hits
   - 有命中 → 按第四节句式改法重写那一段
4. 修复后重跑评分
5. 重复直到 forbidden_words_count = 0 且 structure_hits = []
```

## 七、特别注意

1. **不是所有"书面词"都是AI腔** — "诚然""固然"这种词人也用，看上下文
2. **禁用词在引用/对话中不算** — 如果文章里引用别人说的话包含这些词，不扣分
3. **替换不是机械的** — 不是把"综上所述"机械换成"说白了"，要看上下文语气
4. **叙事类文章天然命中少** — 故事/对话驱动的文章几乎不会触发这些词，它们主要出现在分析/评论类文章中
